# Smart-College-Admission-Recommendation-System
A Smart College Admission Recommendation System that helps students under the counseling quota make informed decisions by comparing engineering colleges and branches based on cutoff marks, location, and category-wise seat availability. Built with HTML, CSS, JavaScript, PHP, and MySQL.

## Features

- AI chatbot to answer student queries
- Personalized college recommendations based on cutoff marks, location, branch, and category
- Location and caste-based filtering (OC, BC, MBC, SC, ST)
- Map view to visualize college locations
- Scholarship details provided for eligible students
- Clean and user-friendly interface

  ## Future Improvements

- Login system with user preference tracking
- Mobile responsive layout or Flutter-based Android app
- Admin dashboard for analytics and management
- Machine learning-based cut-off prediction
- College news and notifications section
